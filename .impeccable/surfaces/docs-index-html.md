# Porter website (docs/)

Scope: the public site, one page per language (10), served by GitHub Pages from docs/. Mode: Persuade.

Audience: Mac developers using Claude Code in Claude Desktop with several accounts, arriving from GitHub, lists, posts and search. Action: download Porter.dmg (latest release); secondary: GitHub. Proof: the app's own UI, rebuilt in HTML with real behavior (usage bars, limit error, reset times); the real file mechanism; the honest notes (unofficial, backups, first-launch block). Constraints: no Claude/Anthropic marks, no invented stats or testimonials, all 10 languages first-class. The user asked for a very modern page with a striking wow effect, not a classic landing; they delegated the structure.

## Direction contract

THESIS: The page is one continuous carry. A real Claude Code session, stopped by "You've hit your limit", is lifted by scroll from a red account card and set down in an account with room, where the error clears and the conversation resumes. It refuses the hero-plus-feature-grid landing.

OWN-WORLD: The app's world at night: a deep plum lobby (#1C1420 to #2A1F2E, from the icon's uniform) where the app's warm paper cards (#FFFDF9, #F5F0E8) glow like lit objects; terracotta (#C96442/#D97757) for the one action, brass (#E8B866) for detail and the porter's path, usage green/orange/red from the app. Gloock display serif, SF system text, SF Mono only for real paths and commands.

STORY: See a stopped session, watch Porter carry it, understand why it works (conversations belong to no account), see profiles side by side and live usage with reset times, read the honest notes, download.

FIRST VIEWPORT: The headline across the top (two lines, ~5.5rem); below it on the left the lead and Download button with "macOS 14+ · free · open source"; right, at real app scale, two account cards, the left one red at 100% with the stopped session; a brass dotted path arcs between them. Menu-bar strip with the porter icon on top.

FORM: Sticky scroll stage (scroll-driven carry), position 6 of 7, seed key 34eab318.

SIGNATURE: the scroll-scrubbed carry (session card travels the brass arc, bars animate, error dissolves). Revised after the finish review: the pull-back to three Claude Desktops is dropped from the motion; profiles are a static section of filled miniature windows, so the page keeps one authored moment.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
