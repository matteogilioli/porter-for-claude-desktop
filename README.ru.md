**Porter** — небольшое приложение для строки меню macOS, работающее с вкладкой **Code** в Claude Desktop. Когда аккаунт упирается в лимит использования, Porter переносит ваши сессии Claude Code на другой аккаунт, и вы продолжаете те же разговоры с того места, где они остановились. Кроме того, он позволяет запускать **несколько Claude Desktop одновременно**, по одному на аккаунт, и наводит порядок в сессиях: архивировать, восстанавливать, удалять и переносить целые проекты.

> [!NOTE]
> Неофициальный проект, не связан с Anthropic. Porter читает и изменяет собственные файлы Claude Desktop, которые не документированы и могут измениться с любым обновлением. Перед каждым изменением он делает резервную копию.

## Несколько Claude Desktop одновременно

<p align="center">
  <img src="assets/readme/profiles.svg" width="100%" alt="Три окна Claude Desktop открыты одновременно, в каждом выполнен вход в свой аккаунт, и все они перечислены в панели Porter">
</p>

Обычно Claude Desktop работает с одним аккаунтом за раз: чтобы войти в другой, нужно выйти и войти снова. С Porter этого делать не придётся.

- **Новый профиль…** открывает отдельный Claude Desktop со своим входом, настройками и списком сессий. Войдите там в другой аккаунт и держите оба окна открытыми.
- Создавайте столько профилей, сколько у вас аккаунтов (рабочий, личный, клиентский…). Все они работают **одновременно**, в Dock и в переключателе ⌘-Tab, как любое приложение.
- Porter показывает каждый профиль с его аккаунтом, последним записанным использованием и сессиями, остановленными лимитом. Он открывает профиль или выводит его на передний план, переименовывает или удаляет.
- Перенос сессий между профилями делается в один клик, а когда лимит одного аккаунта исчерпан, вы просто продолжаете работу в следующем окне.
- **Открывать ссылки в нужном профиле** (в настройках): все профили — одно и то же приложение Claude, поэтому после входа в браузере macOS может вернуть вас в любой из открытых. С этой настройкой Porter передаёт ссылки Claude в профиль, которым вы пользовались последним.

Предпочитаете один Claude Desktop и переключение аккаунтов через выход и вход? Выключите **Несколько профилей** в параметрах: Porter станет показывать аккаунты вместо приложений и переносить сессии старого аккаунта на тот, в который вы вошли.

## Панель в строке меню

<img src="assets/readme/panel.svg" width="44%" align="right" alt="Панель Porter в строке меню: карточки аккаунтов с полосами использования за 5 часов и 7 дней, значок сессий, остановленных лимитом, и кнопка для их переноса">

Нажмите на портье в строке меню, чтобы увидеть все аккаунты разом:

- **Использование за 5 часов и 7 дней** по каждому аккаунту: зелёный, пока есть запас, оранжевый возле лимита, красный, когда он достигнут. Значение, записанное Claude Desktop давно, показывается блёклым с указанием возраста, а 5-часовое окно, которое наверняка уже сбросилось, помечается как сброшенное.
- **Сессии, остановленные лимитом**, подсчитываются по каждому аккаунту и отмечаются точкой на значке в строке меню.
- **Перенести 6 в Personal →**: один клик переносит остановленные сессии на аккаунт с самым большим запасом.
- **Сессии ›** открывает этот аккаунт в главном окне.

## Главное окно

<p align="center">
  <img src="assets/readme/window.svg" width="100%" alt="Главное окно Porter: аккаунты в боковой панели, сессии, сгруппированные по проектам, три выбранные сессии и панель действий с кнопками «Архивировать», «Удалить» и «Перенести в»">
</p>

Все аккаунты и их сессии Claude Code в одном месте:

- **Сессии, сгруппированные по проектам**, с фильтрами (открытые, остановленные лимитом, в архиве), меню проектов и поиском. Зелёный значок отмечает сессии, активные прямо сейчас, чтобы вы не перенесли одну из них посреди ответа.
- **Выбирайте** щелчком, ⇧-щелчком для диапазона или командой *Выбрать все*. Внизу появляется панель действий:
  - **Перенести в…**: выберите целевой аккаунт. Оригиналы архивируются, чтобы одну и ту же сессию не продолжали в двух местах.
  - **Скопировать**: сессии остаются в обоих аккаунтах, и у каждой копии появляется собственный разговор.
  - **Архивировать**, **Восстановить** и **Удалить…** (в Корзину, так что их ещё можно вернуть).
- **Перетаскивайте** сессии на другой аккаунт в боковой панели, чтобы перенести их туда.
- **Перенос папки проекта** (или повторная привязка после того, как вы переместили её в Finder): Porter обновляет все использующие её сессии во всех аккаунтах вместе с разговорами и git worktree. Проекты, чья папка пропала, помечены как *Папка не найдена*.

## Как это работает

<p align="center">
  <img src="assets/readme/how-it-works.svg" width="100%" alt="Схема: Porter копирует небольшой файл сессии из списка сессий одного аккаунта в список другого; разговор остаётся в ~/.claude/projects и общий для всех аккаунтов; чаты хранятся на серверах Anthropic">
</p>

Разговор Claude Code хранится в собственной папке Claude Code, `~/.claude/projects`, которая не принадлежит ни одному аккаунту. Аккаунту принадлежит только **список** сессий в Claude Desktop:

```
<data folder>/claude-code-sessions/<account>/<organization>/local_<session>.json
```

(папка данных по умолчанию — `~/Library/Application Support/Claude`). При переносе сессии этот небольшой файл копируется в список другого аккаунта, ошибка «You've hit your limit» очищается, а вместе с ним переносятся используемые сессией git worktree. Запущенный Claude Desktop держит список в памяти, поэтому Porter сначала закрывает его, а потом снова открывает.

> [!IMPORTANT]
> Porter работает с тем, что Claude Desktop хранит **на вашем Mac**: с сессиями вкладки **Code**. Чаты, в том числе те, где Claude работает с вашими файлами, хранятся на серверах Anthropic и остаются за своим аккаунтом.

## Установка

Нужны **macOS 14** или новее и [Claude Desktop](https://claude.ai/download).

**Загрузка:** скачайте `Porter.dmg` из [последнего релиза](../../releases/latest), откройте его и перетащите **Porter for Claude Desktop** в `Applications`. Приложение не нотаризовано, поэтому при первом запуске macOS его блокирует: откройте **Системные настройки → Конфиденциальность и безопасность** и нажмите **Всё равно открыть** или выполните:

```bash
xattr -dr com.apple.quarantine "/Applications/Porter for Claude Desktop.app"
```

**Сборка из исходников** (Xcode или Command Line Tools):

```bash
git clone https://github.com/matteogilioli/porter-for-claude-desktop.git
cd porter-for-claude-desktop
./scripts/build-app.sh --install
```

Команда соберёт `dist/Porter for Claude Desktop.app` и скопирует его в `~/Applications`. Включите **Открывать при входе** в параметрах, чтобы Porter всегда был под рукой.

Porter говорит на English, Italiano, Español, Français, Deutsch, Português, 简体中文, 日本語, 한국어 и Русский и подстраивается под язык вашего Mac.

## Командная строка

То же приложение переносит сессии из скриптов:

```bash
PORTER="/Applications/Porter for Claude Desktop.app/Contents/MacOS/Porter"
"$PORTER" --list                                        # аккаунты, профили и их списки сессий
"$PORTER" --move --from STORE --to STORE --dry-run      # что произойдёт
"$PORTER" --move --from STORE --to STORE --restart      # перенести (оригиналы архивируются)
"$PORTER" --move --from STORE --to STORE --copy         # вместо этого скопировать
```

`STORE` — путь, который выводит `--list`. Добавьте `--session local_…` (можно повторять) для конкретных сессий, `--include-archived`, чтобы захватить и архивные, и `--data-dir PATH` для папки данных Claude, которую Porter ещё не знает.

Porter закрывает запущенный Claude Desktop только с `--restart` (потом открывает его снова, а место назначения перезапускает или открывает, чтобы оно загрузило сессии); без этого перемещение, которому нужно закрыть приложение, останавливается и называет его. `--dry-run` показывает, какие приложения будут закрыты.

## Полезно знать

- **Отмена:** каждое изменение начинается с резервной копии в `~/Library/Application Support/Porter/backups`. Чтобы отменить перенос, закройте Claude Desktop и скопируйте сохранённые файлы обратно по пути, указанному в `README.txt` внутри копии.
- **Данные об использовании** берутся из того, что записывает Claude Desktop, а он делает это время от времени, пока вы работаете с аккаунтом. Porter показывает, насколько значение устарело. С включённой настройкой **Использование в реальном времени** Porter раз в несколько минут сам запрашивает данные у claude.ai через сессию каждого профиля и показывает, когда сбрасывается каждый лимит, а также лимиты отдельной модели, например Fable. macOS один раз спросит разрешение на использование ключа, который Claude хранит в связке ключей.
- **Одно место за раз:** не продолжайте работать над одной сессией сразу из двух аккаунтов. Именно поэтому перенос архивирует оригинал; если вам действительно нужны две независимые сессии, используйте «Скопировать».
- Используйте только свои аккаунты и соблюдайте условия вашего тарифа Claude.
