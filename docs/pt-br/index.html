Role

A conversa nunca pertenceu a uma conta.

O Claude Code guarda cada conversa numa pasta própria no seu Mac, compartilhada por todas as contas. O que pertence a uma conta é só a pequena lista de sessões do Claude Desktop. O Porter move o item nessa lista, limpa o erro de limite e leva junto os git worktrees que a sessão usa.

  • Antes de cada alteração o Porter faz um backup, e tudo o que ele apaga vai para a Lixeira.
  • Um Claude Desktop aberto mantém a lista na memória, por isso o Porter o encerra antes e o abre de novo depois.

Vários Claude Desktops, lado a lado.

O Claude Desktop normalmente roda uma conta por vez. Com o Porter, cada perfil é um Claude Desktop separado, com login, ajustes e sessões próprios, no Dock e no ⌘-Tab como qualquer app. Quando uma conta chega ao limite, continue trabalhando na próxima janela.

Se quiser, os links do Claude vindos do navegador abrem no perfil que você usou por último.

Dados de exemplo

Todas as contas num relance.

Clique no porteiro na barra de menus: cada conta mostra o uso de 5 horas e de 7 dias, as sessões paradas por um limite e um botão para movê-las para onde há espaço.

Uso em tempo real, quando você quiser.

Ative o Uso em tempo real e o Porter consulta o claude.ai a cada poucos minutos, com a sessão de cada perfil, como faz a tela de uso do Claude. Você também vê quando cada limite reinicia, além dos limites que valem só para um modelo, como o Fable.

Todas as suas sessões, numa só janela.

  • Sessões agrupadas por projeto, com busca e filtros
  • Mova ou copie sessões para outra conta, ou arraste-as até ela
  • Arquive, restaure e apague, com um backup antes de cada alteração
  • Mova a pasta de um projeto e todas as sessões que a usam vão junto

E pela linha de comando.

O mesmo app move sessões a partir dos seus scripts.

$ alias porter="/Applications/Porter for Claude Desktop.app/Contents/MacOS/Porter"$ porter --list # contas, perfis e suas listas de sessões$ porter --move --from WORK --to PERSONAL --dry-run # o que aconteceria, sem alterar nada$ porter --move --from WORK --to PERSONAL --restart # mover, fechando e reabrindo o Claude Desktop

Instale em um minuto.

  1. Baixe

    Baixe o Porter.dmg, abra-o e arraste o Porter para Aplicativos.

    Porter.dmg

  2. Permita uma vez

    O Porter não é notarizado, então o macOS bloqueia a primeira abertura. Abra Ajustes do Sistema → Privacidade e Segurança e clique em Abrir Mesmo Assim, ou execute:

    xattr -dr com.apple.quarantine "/Applications/Porter for Claude Desktop.app"

  3. Entre e comece

    Clique no porteiro na barra de menus, crie um perfil para cada conta e entre. Daí em diante, o Porter se atualiza sozinho.

Bom saber

  • O Porter não é oficial nem tem vínculo com a Anthropic. Ele trabalha com os arquivos do próprio Claude Desktop, que não são documentados e podem mudar a qualquer atualização.
  • Ele trabalha com o que o Claude Desktop guarda no seu Mac: as sessões da aba Code. Os chats ficam nos servidores da Anthropic, com a conta deles.
  • Use só contas que são suas e siga os termos do seu plano do Claude.
