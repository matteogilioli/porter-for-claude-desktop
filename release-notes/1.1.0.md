### New

- **Automatic updates.** Porter now checks for new versions and installs them for you, after asking. You can turn the automatic check off, or check right away, from the options (**Check for Updates…**).
- **Open Links in the Right Profile** (in the options). All profiles are the same Claude app, so after you sign in in the browser, macOS may send you back to any of the open ones. With this on, Porter receives Claude links and passes each one to the profile you used last. The first time, macOS may ask to let Porter control Claude: that is how the link is passed on.

### Good to know

- This is the last version to install by hand: from here on, Porter updates itself.
- After an update, macOS may ask again to let Porter control Claude, if you use **Open Links in the Right Profile**.
