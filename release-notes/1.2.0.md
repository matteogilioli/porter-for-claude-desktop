### New

- **Live Usage** (in the options, off until you turn it on). Claude Desktop records usage only now and then, so the numbers Porter showed could be hours old. With this on, Porter asks claude.ai every few minutes, with the session each profile is signed in with, as Claude's own usage screen does. The first time, macOS asks to let Porter use the key Claude keeps in the Keychain: choose **Always Allow**.
- **When each limit resets**, next to its bar: "today, 14:50", "tomorrow, 20:59" or the date.
- **Limits of a single model**, such as the weekly Fable limit, get a bar of their own. New ones Anthropic adds show up the same way.

### Changed

- The options are grouped: profiles, how Porter behaves, updates.

### Good to know

- Without Live Usage, or when claude.ai does not answer, Porter shows what Claude Desktop recorded, as before.
- After an update, macOS may ask again about the Keychain key.
